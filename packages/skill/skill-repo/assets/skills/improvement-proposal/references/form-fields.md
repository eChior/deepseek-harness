# 表单十五格与效益写法

**这是一页纸摘要。** 每格字数很紧，写不下就把细节放附件。"大约字数"是模板的一屏可见量，超了内容不会丢，脚本会自动加高该行。

| 字段 | 单元格 | 大约字数 | 填什么 |
|---|---|---|---|
| 提案名称 | B4 | 22 | 改了什么 + 对象 + 效果 |
| 提案编号 | H4 | — | **留空**，由精益办编号 |
| 提案人 | B5 | 9 | 姓名；班组提案写组长，其他人写"实施人" |
| 实施人 | E5 | 9 | 实际动手做的人，可与提案人相同 |
| 完成日期 | H5 | 日期 | **日期型格**，填 `2026-09-14` 格式 |
| 提案类型 | B6 | 33 | 必须逐字用那 7 个写法（`物耗/能耗(Cost)`、`效率(Productivity)`、`安全(Safety)`、`其他(Other)`、`产能(Ability)`、`品质(Quality)`、`环境(Environment)`），简写会让台账多出一个重复选项 |
| 业务类型 | B7 | 33 | 第 3 轮问出来的那类 |
| 存在问题 | F8 | 67 | 改善前的现状 + 造成什么损失。要事实和数字，不写抱怨 |
| 主要原因 | F9 | 83 | 为什么会这样。追到可改的那一层，别写"员工不认真"这类改不了的 |
| 改善对策 | F10 | 83 | 具体做了什么（方案 + 关键动作）。不要只写结果，要写怎么做的 |
| 控制措施 | F11 | 117 | 选填但建议填：怎么防止反弹 |
| 成果标准化 | B12 | 100 | 选填但建议填：形成了什么文件/工具，**要给文件名称与编号** |
| 无形效益 | C13 | 88 | 用"从 X 变成 Y"的事实写，不硬折成金额 |
| 经济效益 | F14 | 数字 | **数值型格**，单位元；没有就填 0 |
| 计算方式 | C15 | 88 | 效益怎么算出来的（公式 + 取值 + 年化依据） |

表单只有两条数据有效性约束：完成日期 = 日期型、经济效益 = 数值型，其余是自由文本。

**表末"审核记录"三行提案人不要填**：初评由部门/车间管理人员（涉及经济效益的还要财务人员核准），复评由精益办。

## 效益写法

```
工时节约   = (改善前单次耗时 − 改善后单次耗时) × 频次/班 × 班次/天 × 作业天数/年
物料节约   = (改善前单耗 − 改善后单耗) × 年产量 × 单价
能耗节约   = (改善前功率 × 运行时长 − 改善后功率 × 运行时长) × 电价
质量损失减少 = (改善前不良率 − 改善后不良率) × 年产量 × 单件损失
投入       = 材料 + 外购件 + 加工/施工 + 设备折旧值 + 改造停机损失 + 试错报废
```

- **说清年化依据**：一年按多少天、多少班折算要写出来（如"2 班/天 × 250 天 = 500 班/年"）。
- **改善前后同口径**：都用次数和时间，或都用小时，别一处一个单位。
- **工时 ≠ 钱。** 省下的工时只有在"减少加班 / 用于增产 / 减少定员"三种情形下才能折金额；人没减、产没增、班没少就**不要折钱**，写进无形效益。硬折出来的金额，财务一问"这钱公司账上哪里少了"就答不上来。
- **区分一次性与持续性**：一次性节约别乘 12 当年化。
- **扣掉成本**：改造停机、试错报废、新增耗材，都要从收益里减掉；设备类投入按**折旧值**计。
- **计算方式格只写一行**：`(40−5)min × 15次/班 × 2班/天 × 250天/年 ÷ 60 = 72.9 h/年`。写不下的演算做附件，末尾写"详见附件×"。**经济效益填 0 时，这里写清为什么不折钱。**
- **不要写**：没发生的损失（"避免了一次可能的事故，价值 10 万"）；同一份效益在工时和人工成本里各算一遍；"同行业平均效益"这种外部数据。
